# Customers Trend Analysis

## Overview
Customer Trend Analysis is a data analytics project built using SQL and Power BI to analyze customer behavior, sales performance, and business trends. The project converts raw transactional data into actionable insights through optimized SQL queries and interactive Power BI dashboards.

## Tech Stack
- SQL – Data extraction, transformation, and cleaning
- Power BI – Data modeling, DAX measures, and visualization
- Relational Database – Source of customer and sales data

## Objectives
- Analyze customer purchasing behavior
- Identify sales and revenue trends
- Segment customers based on key metrics
- Enable data-driven business decisions

## Key Features
- Interactive Power BI dashboards
- Time-based customer and sales trend analysis
- KPI monitoring (Revenue, Customer Count, Growth Rate)
- Optimized SQL queries for performance
- Clean and structured data model

## Project Workflow
1. Extract data from the database using SQL
2. Clean and transform data using SQL queries
3. Load data into Power BI
4. Create relationships and data model
5. Build DAX measures
6. Design interactive dashboards

## Dashboard Insights
- Customer growth over time
- Revenue trends by region and segment
- Top-performing customers
- New vs repeat customer analysis

## How to Use
1. Execute SQL scripts to prepare the dataset
2. Open the Power BI `.pbix` file
3. Refresh the data connection
4. Explore the dashboards
